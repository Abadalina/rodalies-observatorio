Como se construye

Cada 60 segundos se consulta el feed GTFS-Realtime de Renfe y se guarda lo que dice de cada tren en cada parada. Nada se descarta: una circulacion que el horario no reconoce se guarda marcada, no se tira, porque perder una fila es irreversible y un cruce vacio no.

Lo que ves arriba sale de esa serie, no de una estimacion. Si un dia falta, se nota; no se rellena.
