Cómo se construye

Cada 60 segundos se consulta el feed GTFS-Realtime de Renfe y se guarda lo que dice de cada tren en cada parada. Nada se descarta: una circulación que el horario no reconoce se guarda marcada, no se tira, porque perder una fila es irreversible y un cruce vacío no.

Lo que ves arriba sale de esa serie, no de una estimación. Si un día falta, se nota; no se rellena.
